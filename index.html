How this winner was proven

The worker submits an ECVRF proof. The program checks it against the round commitment (round id, pot and sorted player wallets). The first 8 bytes of the verified output, modulo the number of players, select the winner.

Anyone can re-check that transaction on the explorer. If the proof does not match, the program rejects the settlement.
